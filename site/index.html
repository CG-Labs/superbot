Self-host

Run it on your servers, even air-gapped

SuperBot is open source. Install it on your own server with one script or Docker Compose, or from an offline bundle with no internet at all. Your data stays where you put it.

  • Any harness: Claude Code, Codex, Pi or Hermes Agent
  • Signed offline bundles for x86_64 and aarch64
  • Backups and restores, drilled in CI
❯ sudo bash install.sh --offline <bundle> \
    --bundle-sha256 <hex> --domain <name> \
    --tls-cert <pem> --tls-key <pem>
# nothing is downloaded or built
